# Γλωσσάρι — Ελληνικά ↔ Αγγλικά

> Κάθε τεχνικός όρος που χρησιμοποιείται σε αυτό το αποθετήριο, με απλή εξήγηση.
> Η **αγγλική έκδοση** αυτής της σελίδας είναι το [`GLOSSARY.md`](GLOSSARY.md).
>
> **Σύμβαση που χρησιμοποιείται παντού σε αυτό το αποθετήριο:** οι εντολές, τα ονόματα
> εργαλείων, οι σημαίες (flags), οι διαδρομές αρχείων και η πραγματική έξοδος τερματικού
> παραμένουν στα **Αγγλικά**· μόνο οι *εξηγήσεις* μεταφράζονται. Ένας όρος λοιπόν μπορεί να
> εμφανίζεται με δύο τρόπους — ο αγγλικός όρος όπως θα τον πληκτρολογήσετε πραγματικά, και η
> ελληνική λέξη που χρησιμοποιείται στην εξήγηση.

---

## Α. Μεθοδολογία

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Αναγνώριση | Reconnaissance | Συλλογή πληροφοριών για τον στόχο **χωρίς** (ή πριν) να τον αγγίξετε: διευθύνσεις, ανοιχτές θύρες, υπηρεσίες. |
| Απαρίθμηση | Enumeration | Ενεργή ερώτηση σε μια υπηρεσία για εξαγωγή χρηστών, shares, εκδόσεων, κρυφών διαδρομών. Η φάση που οι αρχάριοι παραλείπουν. |
| Εκμετάλλευση / Πρόσβαση | Foothold / Exploitation | Μετατροπή ενός ευρήματος στο πρώτο κέλυφος (εκτέλεση κώδικα). |
| Αναβάθμιση προνομίων | Privilege escalation (privesc) | Από απλός χρήστης σε `root`/Administrator. |
| Μετά-εκμετάλλευση | Post-exploitation | Τι κάνετε μετά το root: pivot, κυνήγι, καθαρισμός, αναφορά. |
| Επιφάνεια επίθεσης | Attack surface | Το σύνολο όσων μπορεί να αγγίξει ένας επιτιθέμενος (θύρες, εφαρμογές, χρήστες). |
| Αλυσίδα επίθεσης | Kill chain | Τα διατεταγμένα βήματα από την αναγνώριση ως τον στόχο. |
| Παγίδα / Αδιέξοδο | Rabbit hole | Εύρημα που φαίνεται υποσχόμενο αλλά δεν οδηγεί πουθενά. |

## Β. Δικτύωση

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Υποδίκτυο / CIDR | Subnet / CIDR | Μπλοκ διευθύνσεων με κοινό πρόθεμα, π.χ. `192.168.56.0/24` (256 διευθύνσεις). |
| Διεύθυνση IP | IP address | Διεύθυνση επιπέδου 3 ενός ξενιστή. |
| Διεύθυνση MAC | MAC address | Διεύθυνση υλικού επιπέδου 2 μιας διεπαφής. |
| ARP | ARP | Πρωτόκολλο που αντιστοιχίζει IP σε MAC στο τοπικό τμήμα. |
| Θύρα | Port | Αριθμημένο τελικό σημείο σε έναν ξενιστή· μια υπηρεσία «ακούει» εκεί. |
| Χειραψία TCP τριών βημάτων | TCP three-way handshake | `SYN → SYN/ACK → ACK`· η βάση κάθε σάρωσης θυρών. |
| UDP | UDP | Πρωτόκολλο χωρίς σύνδεση· οι σαρώσεις είναι αργές και δείχνουν `open|filtered`. |
| Πύλη | Gateway | Ο δρομολογητής για πρόσβαση σε άλλα δίκτυα. |
| Τείχος προστασίας | Firewall | Φιλτράρει κίνηση· εισερχόμενη (ingress) και **εξερχόμενη** (egress). |
| Τείχος εξόδου | Egress firewall | Περιορίζει τις *εξερχόμενες* συνδέσεις — γι' αυτό μπορεί να αποτύχει ένα reverse shell. |
| Port knocking | Port knocking | Μυστική ακολουθία συνδέσεων που ανοίγει μια θύρα. |

## Γ. Σάρωση & απαρίθμηση

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Σάρωση θυρών | Port scan | Έλεγχος ποιες θύρες είναι ανοιχτές/κλειστές/φιλτραρισμένες. |
| Ανίχνευση υπηρεσίας/έκδοσης | Service/version detection | `nmap -sV`: ποιο λογισμικό και ποια έκδοση κρύβεται πίσω από μια θύρα. |
| Banner | Banner | Ο χαιρετισμός που στέλνει μια υπηρεσία· συχνά διαρρέει την έκδοση. |
| Εύρεση περιεχομένου | Content discovery | Brute-force κρυφών αρχείων/καταλόγων με λίστα λέξεων. |
| Λίστα λέξεων | Wordlist | Λεξικό υποψήφιων ονομάτων/κωδικών. |
| Σενάριο NSE | NSE script | Σενάριο `nmap` (π.χ. `vuln`, `http-title`). |
| Κενή συνεδρία | Null session | Σύνδεση SMB χωρίς διαπιστευτήρια. |
| RID cycling | RID cycling | Απαρίθμηση χρηστών SMB επαναλαμβάνοντας σχετικά αναγνωριστικά. |
| Κοινόχρηστος φάκελος | Share | Κατάλογος εξαγόμενος μέσω SMB. |

## Δ. Web

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Κωδικός κατάστασης HTTP | HTTP status code | `200` υπάρχει, `301/302` redirect, `403` απαγορεύεται, `404` λείπει. |
| GET / POST | GET / POST | Μέθοδοι αίτησης: ανάκτηση vs υποβολή. |
| Κεφαλίδα | Header | Μεταδεδομένα μαζί με αίτηση ή απόκριση. |
| Εισαγωγή SQL (SQLi) | SQL injection | Έγχυση SQL μέσω μη καθαρισμένης εισόδου. |
| Τυφλή SQLi | Blind SQLi | Δεν επιστρέφονται δεδομένα· συμπεραίνεται από χρόνο ή boolean αποκρίσεις. |
| Τοπική συμπερίληψη αρχείων | Local File Inclusion (LFI) | Η εφαρμογή διαβάζει αρχείο από τον server. |
| Απομακρυσμένη συμπερίληψη | Remote File Inclusion (RFI) | Η εφαρμογή συμπεριλαμβάνει αρχείο από μηχάνημα του επιτιθέμενου. |
| Εισαγωγή εντολών | Command injection | Πέρασμα shell metacharacters σε εντολή που τρέχει η εφαρμογή. |
| Παράκαμψη φίλτρου μεταφόρτωσης | File upload bypass | Ήττα φίλτρου μεταφόρτωσης (κατάληξη, MIME, magic bytes). |
| Web shell | Web shell | Σενάριο που εκτελεί εντολές που λαμβάνει μέσω HTTP. |
| Σύστημα διαχείρισης περιεχομένου | CMS | WordPress, Drupal, Joomla, Koken… |
| Διασχίζοντας διαδρομές | Path traversal | Χρήση `../` για διαφυγή από κατάλογο. |

## Ε. Διαπιστευτήρια & κρυπτογραφία

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Κωδικοποίηση | Encoding | Αντιστρέψιμη αλλαγή μορφής **χωρίς κλειδί** (base64, hex). Μηδέν ασφάλεια. |
| Κατακερματισμός | Hashing | Μετασχηματισμός μίας κατεύθυνσης (MD5, SHA-256, bcrypt). Για κωδικούς. |
| Κρυπτογράφηση | Encryption | Αντιστρέψιμη **με κλειδί** (AES, RSA). Παρέχει εμπιστευτικότητα. |
| Salt | Salt (αλάτι) | Τυχαία δεδομένα πριν το hashing, ώστε ίδιοι κωδικοί να δίνουν διαφορετικό hash. |
| Γύροι κατακερματισμού | Hash rounds | Επανάληψη του hash για επιβράδυνση της μαντεψιάς (phpass: 8192). |
| Επίθεση λεξικού | Wordlist attack | Δοκιμή κωδικών από λίστα. |
| Brute force | Brute force | Δοκιμή κάθε συνδυασμού. |
| Ψεκασμός κωδικών | Password spraying | Ένας κωδικός σε πολλούς λογαριασμούς (αποφεύγει lockout). |
| Credential stuffing | Credential stuffing | Επανάχρηση διαρρευσάντων ζευγών χρήστη/κωδικού. |
| Επανάχρηση διαπιστευτηρίων | Credential reuse | Ο ίδιος κωδικός δουλεύει σε άλλη υπηρεσία. |
| Σπασίματα εκτός σύνδεσης | Offline cracking | Σπάσιμο κλεμμένου hash τοπικά με John/hashcat. |
| Πίνακας rainbow | Rainbow table | Προϋπολογισμένα hashes· εξουδετερώνεται με salt. |
| GPG / PGP | GPG / PGP | Κρυπτογράφηση και υπογραφή δημόσιου κλειδιού. |
| Συμμετρική / ασύμμετρη | Symmetric / asymmetric | Ένα κοινό κλειδί vs ζεύγος κλειδιών (δημόσιο + ιδιωτικό). |

## ΣΤ. Κελύφη & εκμετάλλευση

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| Reverse shell | Reverse shell | Ο **στόχος συνδέεται πίσω** στον επιτιθέμενο. |
| Bind shell | Bind shell | Ο στόχος **ακούει**· ο επιτιθέμενος συνδέεται. |
| Payload (φορτίο) | Payload | Ο κώδικας που εκτελείται στον στόχο μετά την εκμετάλλευση. |
| Σταδιακό / μονοκόμματο | Staged / stageless | Παράδοση payload σε κομμάτια vs ολόκληρο. |
| Αναβάθμιση TTY | TTY upgrade | Κάνει ένα «χαζό» κέλυφος πλήρως διαδραστικό (`pty.spawn`, `stty raw`). |
| Meterpreter | Meterpreter | Το προηγμένο payload μετά-εκμετάλλευσης του Metasploit. |
| Exploit (εκμετάλλευση) | Exploit | Κώδικας ή τεχνική που καταχράται μια ευπάθεια. |
| CVE / CVSS | CVE / CVSS | Δημόσιο αναγνωριστικό ευπάθειας / βαθμολογία σοβαρότητας. |
| Απόδειξη έννοιας (PoC) | Proof of concept (PoC) | Επίδειξη exploit. |

## Ζ. Αναβάθμιση προνομίων Linux

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| `sudo` | `sudo` | Εκτέλεση εντολής ως root (ή άλλος χρήστης). |
| SUID / SGID | SUID / SGID | Bit εκτέλεσης ως ιδιοκτήτης / ως ομάδα. |
| Capabilities (ικανότητες) | Capabilities | Λεπτομερή προνόμια root σε ένα εκτελέσιμο (π.χ. `cap_dac_read_search`). |
| Χρονοπρογραμματισμένη εργασία | Cron job | Εντολή σε χρονοδιάγραμμα, συχνά ως root. |
| Παρεμβολή στο PATH | PATH hijacking | Η εκτέλεση *δικού σας* αρχείου σκιάζοντας ένα όνομα εντολής. |
| Εγγράψιμο από όλους | World-writable | Αρχείο/κατάλογος που αλλάζει ο καθένας (`chmod 777`). |
| `euid` vs `uid` | `euid` vs `uid` | Effective (τι μπορείς) vs real (ποιος είσαι) αναγνωριστικό χρήστη. |
| Kernel exploit | Kernel exploit | Κατάχρηση ευπάθειας στον πυρήνα του OS. |
| Διαφυγή από container | Container escape | Διαφυγή από Docker/LXD στον οικοδεσπότη. |

## Η. Συστήματα & άμυνα (Κεφάλαια 07–11)

| Ελληνικά | Αγγλικά | Σημασία |
| --- | --- | --- |
| DAC | DAC | Discretionary Access Control — τα bit `rwx` ιδιοκτήτη/ομάδας/λοιπών. |
| MAC | MAC | Mandatory Access Control — πολιτική πυρήνα (SELinux, AppArmor). |
| ACL | ACL | Access Control List — δικαιώματα ανά χρήστη πέρα από τα εννέα bit. |
| `umask` | `umask` | Μάσκα που αφαιρεί bit από νέα αρχεία. |
| SELinux context | SELinux context | Ετικέτα `user:role:type:level` στην οποία δρουν οι πολιτικές MAC. |
| Προφίλ AppArmor | AppArmor profile | Πολιτική βάσει διαδρομών για τα αρχεία που αγγίζει ένα πρόγραμμα. |
| PAM | PAM | Pluggable Authentication Modules — το πλαίσιο σύνδεσης/πιστοποίησης. |
| Αρχείο καταγραφής ελέγχου | Audit log | Πού καταγράφονται απορρίψεις/γεγονότα (`ausearch`, `/var/log`). |
| Sandboxing | Sandboxing | Περιορισμός του τι κάνει ο κώδικας αφού τρέξει (systemd, seccomp). |
| IOC (δείκτης συμβιβασμού) | IOC | Indicator of Compromise — απόδειξη εισβολής. |
| Στατική / δυναμική ανάλυση | Static / dynamic analysis | Επιθεώρηση αρχείου χωρίς εκτέλεση vs παρατήρηση ενώ τρέχει. |
| Κανόνας YARA | YARA rule | Μοτίβο που περιγράφει και ανιχνεύει κακόβουλο λογισμικό. |
