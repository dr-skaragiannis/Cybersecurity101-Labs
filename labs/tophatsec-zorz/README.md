### Learn the fundamentals now

This walkthrough is pending, but the concepts it would rely on are already documented
in the repository primer — [**`docs/CONCEPTS.md`**](../../docs/CONCEPTS.md). Every
command in every completed walkthrough here is explained against it, so reading the
primer first means you can follow any lab in this collection.

Work through it in this order:

1. [§2 — Networking you must know first](../../docs/CONCEPTS.md#2-networking-you-must-know-first) — IP addresses and CIDR, MAC and ARP, ports, and the TCP three-way handshake that makes port scanning possible at all
2. [§3 — What is reconnaissance?](../../docs/CONCEPTS.md#3-what-is-reconnaissance) and [§4 — Host discovery](../../docs/CONCEPTS.md#4-host-discovery--who-is-out-there)
3. [§5 — What is nmap, and how does it work?](../../docs/CONCEPTS.md#5-what-is-nmap-and-how-does-it-work) — scan types, `-sV`, `-sC`, port selection, timing, and how to read the output
4. [§6 — What is enumeration?](../../docs/CONCEPTS.md#6-what-is-enumeration) — and why it is the phase most people skip
5. [§7 — What is a wordlist?](../../docs/CONCEPTS.md#7-what-is-a-wordlist) — where lists come from, and wordlist vs brute force vs spraying vs stuffing
6. [§10 — Encoding vs hashing vs encryption](../../docs/CONCEPTS.md#10-encoding-vs-hashing-vs-encryption) — the distinction that decides whether "decode this" is a one-liner or a crack
7. [§12 — Shells: bind, reverse, and TTYs](../../docs/CONCEPTS.md#12-shells--bind-reverse-and-ttys)
8. [§15 — Linux privilege escalation](../../docs/CONCEPTS.md#15-linux-privilege-escalation) — the checklist, in the order you should work it

See also [**`docs/BEGINNER-PATH.md`**](../../docs/BEGINNER-PATH.md) for a recommended
order in which to attempt the machines themselves, and
[**`docs/TOOLS.md`**](../../docs/TOOLS.md) for what each tool is for.
