# Μαθησιακή Διαδρομή 1 — Εισαγωγή στην Κυβερνοασφάλεια

> **Ελληνική έκδοση.** Αυτός ο φάκελος είναι η πλήρης ελληνική μετάφραση της
> [`Learning Path 1 - Introduction to Cybersecurity`](<../Learning%20Path%201%20-%20Introduction%20to%20Cybersecurity/README.md>).
> Οι **εντολές, τα ονόματα εργαλείων και τα αποτελέσματα του τερματικού παραμένουν στα Αγγλικά** —
> έτσι ακριβώς θα τα δείτε στον υπολογιστή σας και στη διεθνή βιβλιογραφία. Όλο το επεξηγηματικό
> κείμενο είναι στα Ελληνικά.

Μία **δομημένη διαδρομή 13 εργαστηρίων** που σας πάει από το «δεν έχω ανοίξει ποτέ Kali»
μέχρι το «πήρα root σε ένα μηχάνημα με αλυσίδα τεχνικών». Δεν είναι κατάλογος· είναι
**πρόγραμμα σπουδών** με σειρά, θεωρία πριν από την πράξη, και έναν έλεγχο γνώσεων στο τέλος
κάθε σταδίου.

**Χρόνος:** περίπου **55–80 ώρες** συνολικά (4–6 ώρες ανά μηχάνημα, συν τα θεωρητικά κεφάλαια).
**Επίπεδο:** απόλυτα αρχάριος → ελαφρώς προχωρημένος (ζώνες δυσκολίας 2–3 του αποθετηρίου).

---

## Σε ποιον απευθύνεται

Αυτή η διαδρομή είναι για εσάς αν:

- Ξέρετε τι είναι μια διεύθυνση IP αλλά δεν έχετε τρέξει ποτέ `nmap`.
- Έχετε ακολουθήσει ένα tutorial «χακάρισμα σε 5 λεπτά» και δεν καταλάβατε *γιατί* δούλεψε.
- Θέλετε να μάθετε τη **μέθοδο** (αναγνώριση → απαρίθμηση → εκμετάλλευση → αναβάθμιση προνομίων
  → αναφορά), όχι μια λίστα από εργαλεία.
- Διαβάζετε ένα αποτέλεσμα τερματικού και δεν ξέρετε ποιες γραμμές έχουν σημασία.

**Δεν** είναι για εσάς αν θέλετε: ανάπτυξη δικών σας exploits, υπερχείλιση μνήμης
(buffer overflow), Active Directory, ή προχωρημένες τεχνικές απόκρυψης. Αυτά ανήκουν στη
**Μαθησιακή Διαδρομή 2** (δείτε το τέλος αυτού του αρχείου).

## Οι κανόνες του παιχνιδιού

1. **Μόνο σε εργαστήριο.** Επιτίθεστε αποκλειστικά σε μηχανήματα που έχετε κατεβάσει εσείς
   (VulnHub) ή σε εικονικά συστήματα δικά σας. Ποτέ σε συστήματα τρίτων. Αυτό δεν είναι
   ηθικολογία μόνο· στην Ελλάδα είναι και **νόμος** (Ν. 2472/1997, Ν. 4411/2016,
   Οδηγία 2013/40/ΕΕ).
2. **Ξεχωριστό δίκτυο.** Το εργαστήριο ζει σε **host-only** ή **internal network** του
   VirtualBox, απομονωμένο από το δίκτυό σας. Όχι bridged.
3. **Καταγράφετε τα πάντα.** Από την πρώτη εντολή. Η αναφορά που θα γράψετε στο τέλος είναι
   το πραγματικό εκπαιδευτικό προϊόν — το root shell είναι απλώς η απόδειξη.
4. **Καταλαβαίνετε πριν προχωρήσετε.** Αν μια εντολή δούλεψε και δεν ξέρετε γιατί,
   σταματήστε και διαβάστε το αντίστοιχο κεφάλαιο θεωρίας. Ένας κατάλογος εντολών που
   αντιγράφετε δεν είναι γνώση.

## Πώς να μελετήσετε κάθε μηχάνημα

Αυτή είναι η ρουτίνα. **Μην την παραλείπετε** — είναι αυτή που μετατρέπει 13 μηχανήματα
σε εκπαίδευση αντί για 13 walkthroughs.

| # | Βήμα | Τι σημαίνει στην πράξη |
| --- | --- | --- |
| 1 | **Διαβάστε το κεφάλαιο θεωρίας** | Πριν ανοίξετε το μηχάνημα. Αν το μηχάνημα 9 χρησιμοποιεί SQL injection, διαβάστε πρώτα το [Κεφάλαιο 02](02-Επιθέσεις-στο-Web.md). |
| 2 | **Κάντε το με το walkthrough ανοιχτό** | Την πρώτη φορά, ναι. Στόχος είναι να δείτε πώς μοιάζει μια επιτυχημένη αλυσίδα. |
| 3 | **Ξανακάντε το από μνήμης** | Επαναφορά του VM στο snapshot, walkthrough **κλειστό**. Εδώ αποκτάτε την τεχνική. |
| 4 | **Γράψτε αναφορά μιας σελίδας** | Διεύθυνση IP · ανοιχτές θύρες · ευπάθειες · αλυσίδα εκμετάλλευσης · πώς διορθώνεται η καθεμία. |
| 5 | **Απαντήστε στις ερωτήσεις** | Κάθε κάρτα μηχανήματος τελειώνει με «Ερωτήσεις επανάληψης». Αν δεν μπορείτε να απαντήσετε, ξαναδιαβάστε το κεφάλαιο. |

> ### 💡 Ο πιο χρήσιμος κανόνας αυτής της σελίδας
>
> **Κάθε κεφάλαιο τελειώνει με «Σημειωμένες εντολές» και κάθε κάρτα μηχανήματος με
> «Οι εντολές, αναλυτικά».** Εκεί εξηγείται κάθε εντολή που θα πληκτρολογήσετε: τι σημαίνει
> κάθε όρισμα και κάθε παράμετρος (token by token), **ποιο ακριβώς αποτέλεσμα πρέπει να δείτε
> στο τερματικό**, και πώς διαβάζεται αυτό το αποτέλεσμα γραμμή προς γραμμή. Αν το δικό σας
> αποτέλεσμα διαφέρει, η ενότητα αυτή σας λέει και αν η διαφορά έχει σημασία.

## Τι θα έχετε εξασκήσει στο τέλος

Μετά τα 13 μηχανήματα θα έχετε εκτελέσει, κατανοήσει και εξηγήσει:

| Κατηγορία | Συγκεκριμένες τεχνικές |
| --- | --- |
| **Αναγνώριση** | `netdiscover`, `arp-scan`, `nmap -sn`, `nmap -p- -sV -sC -oA`, `masscan`, UDP scanning και το `open\|filtered` |
| **Απαρίθμηση** | FTP (`ftp`, `curl ftp://`), SMB (`smbclient`, `smbmap`, `enum4linux`, `crackmapexec`), SMTP (`smtp-user-enum`, `nc`), HTTP (`dirb`, `gobuster`, `ffuf`, `nikto`, `whatweb`), MySQL/Postgres |
| **Επιθέσεις web** | SQL injection (boolean, time-based, UNION, `sqlmap`), LFI/RFI και `php://filter`, OS command injection, ανεπαρκής έλεγχος μεταφορτώσεων και οι 5 τρόποι παράκαμψής του, δηλητηρίαση αρχείων καταγραφής, ευπάθειες CMS (Drupal, WordPress, Koken) |
| **Διαπιστευτήρια** | Λίστες λέξεων (γενικές vs στοχευμένες με `cewl`), hash-identifier, `john`, `hashcat` (modes, κανόνες, benchmarks), `hydra` (SSH/FTP/HTTP), password spraying, επανάχρηση διαπιστευτηρίων |
| **Αναβάθμιση προνομίων (Linux)** | `sudo -l` και GTFOBins, SUID/SGID, Linux capabilities, cron jobs και `pspy`, εγγράψιμα αρχεία, τεχνική `/etc/passwd`, παρεμβολή στο PATH, ομάδες (`docker`, `lxd`), kernel exploits |
| **Κελύφη και μετά-εκμετάλλευση** | Reverse vs bind shells, 8 payload σε 5 γλώσσες, αναβάθμιση TTY (`pty.spawn`, `stty raw`), διαφυγή από `rbash`, εμμονή, διαφυγή από container, καθαρισμός |
| **Επαγγελματισμός** | Σημειώσεις, χρονολόγιο, αναφορά ανά μηχάνημα, αμυντικές προτάσεις, καθαρισμός του εργαστηρίου |

## Έχετε ολοκληρώσει τη Μαθησιακή Διαδρομή 1 όταν…

1. Έχετε γράψει **13 αναφορές** μιας σελίδας.
2. Μπορείτε να εξηγήσετε **τι κάνει κάθε σημαία** στις εντολές `nmap`, `sqlmap`, `john`,
   `hashcat`, `hydra`, `wpscan`, `ffuf`, `smbclient`, `getcap` και `find -perm`.
3. Μπορείτε να διαβάσετε ένα αποτέλεσμα `id` και να πείτε αμέσως αν έχετε root
   (`uid=0` ή `euid=0`) και γιατί τα δύο δεν είναι το ίδιο πράγμα.
4. Ξέρετε τη **σειρά** ελέγχου αναβάθμισης προνομίων από καρδιάς: `sudo -l` → SUID →
   capabilities → cron/pspy → εγγράψιμα αρχεία → ομάδες → kernel.
5. Έχετε κάνει τουλάχιστον **δύο μηχανήματα από μνήμης**, χωρίς walkthrough.
