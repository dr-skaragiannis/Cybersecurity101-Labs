Complete index of **708 virtual machines (OVAs)** hosted on [VulnHub](https://vulnhub.com/).

**98 of them already have a full local walkthrough** — marked ✅ in the
*Writeup* column below. The remainder have a metadata stub in
`labs/<slug>/README.md` carrying the machine's name, description, download link and
writeup-search links, ready to be filled in.

Useful starting points:

- [`PROGRESS.md`](PROGRESS.md) — just the finished walkthroughs, with authors and dates.
- [`BEGINNER-PATH.md`](BEGINNER-PATH.md) — a suggested learning order for newcomers.
- [`LAB-SETUP.md`](LAB-SETUP.md) — how to import an OVA and set up an isolated lab network.
- [`TOOLS.md`](TOOLS.md) — the tools used across these walkthroughs.
